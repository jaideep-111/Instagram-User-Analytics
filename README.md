# Instagram User Analytics using SQL

## 📌 Project Overview
This project analyzes Instagram user data using **SQL** to answer real-world business, marketing, and investor-related questions. The goal is to extract actionable insights from relational data and support data-driven decision-making.

## 🗂️ Dataset Description
The dataset contains Instagram-like relational tables, including:
- Users
- Photos
- Likes
- Tags
- Photo_Tags

These tables were used to simulate a real production-style social media database.

## 🛠️ Tech Stack
- MySQL
- MySQL Workbench
- SQL (Joins, Subqueries, CTEs, Aggregations)

## 🔍 Project Approach
1. Created and structured a relational database using the provided dataset.
2. Explored relationships between users, posts, likes, and hashtags.
3. Wrote optimized SQL queries to answer business-driven questions.
4. Interpreted query outputs to derive meaningful insights.

## 📊 Business & Marketing Analysis

### 1️⃣ Loyal User Identification
- Identified the **oldest users** on the platform based on account creation date.
- Helped marketing teams design **loyalty reward programs**.

### 2️⃣ Inactive User Management
- Found users who **never posted a photo** using LEFT JOINs.
- Useful for re-engagement and email marketing campaigns.

### 3️⃣ Contest Winner Analysis
- Determined the **user with the most likes on a single photo**.
- Supported fair and data-backed contest winner declaration.

### 4️⃣ Hashtag Research
- Identified the **top 5 most-used hashtags** on the platform.
- Helps brands improve reach and engagement in marketing campaigns.

### 5️⃣ Ad Campaign Optimization
- Analyzed user sign-up patterns to find the **best day of the week** for launching ad campaigns.

## 📈 Investor-Focused Metrics

### User Engagement
- Calculated **average number of posts per user**.
- Assessed overall platform activity and content creation trends.

### Bots & Fake Account Detection
- Identified potential **bot or fake accounts** by detecting users who liked every single photo.
- Provided insights into platform integrity and quality of engagement.
